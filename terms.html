Documentation / Usage Guidelines

Terms and Conditions

These terms describe the intended educational use and practical scope of the FrontendMastery quiz website.

1. Educational Purpose

FrontendMastery is an educational self-assessment project created to help students and developers review core concepts in HTML5, CSS3, JavaScript (ES6+), DOM manipulation, and web accessibility. Completing the quiz or exporting a results file is for personal study and practice only and does not represent an accredited certification or professional qualification.

2. Appropriate Use of the Application

You may use the quiz interface, review the question explanations, download your session results in JSON format, and inspect the source code for learning and reference. When interacting with the hosted site, please do not attempt to disrupt normal asset delivery or misrepresent exported JSON results as formal examination credentials.

3. Accuracy and Technical Scope

The 15 questions and explanations in data/questions.json are written to reflect standard W3C, WHATWG, and ECMAScript specifications. However, browser implementations and web standards evolve over time. Always consult official specification documents and current browser compatibility tables when making production engineering decisions.

4. As-Is Availability

This project is provided on an "as-is" basis for educational demonstration without warranties of continuous availability or fitness for a particular commercial purpose. Because quiz state is stored in temporary browser memory, refreshing or closing the page before exporting your results will reset your active session.
