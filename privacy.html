Documentation / Data Practices

Privacy Policy

This policy explains how the FrontendMastery application handles quiz activity, browser state, and exported results based on the actual client-side source code.

1. Local Browser Processing

FrontendMastery is a client-side web application built with HTML5, CSS3, and Vanilla JavaScript. When you start the quiz, select answers, view explanations, or track elapsed time, all state is held temporarily in your browser memory (JavaScript variables) for the duration of your active page session.

Your selected answers, score, accuracy percentage, and elapsed time are calculated exclusively inside your browser and are not transmitted by the application to any application database or remote API endpoint.

2. Question Bank Loading

When the page loads, the application makes a standard HTTP fetch() request to retrieve the static file data/questions.json from the same web server hosting the site. No user-entered information is sent with this request.

3. Downloaded JSON Results

When you click the Download Results (JSON) button on the completion screen, the application constructs a JSON document locally in your browser using the Blob and URL.createObjectURL web APIs. That file is saved directly to your device through your browser download manager. Once you download the file, its storage and sharing are controlled entirely on your own device.

4. Browser Storage, Cookies, and Third-Party Scripts

The FrontendMastery application code does not read or write browser cookies, does not store data in localStorage, sessionStorage, or IndexedDB, and does not load external analytics, advertising, or font tracking scripts. Reloading or closing the browser tab clears your current quiz progress from memory.

5. Hosting Infrastructure Logs

While the FrontendMastery application code itself does not collect personal data, the static web server or hosting platform serving these files (such as GitHub Pages or your cloud hosting provider) processes standard HTTP requests to deliver the HTML, CSS, JavaScript, SVG, and JSON assets to your browser. Hosting providers typically record standard network request metadata (such as IP address, requested URL path, timestamp, and user-agent header) for security and operational reliability under their own platform privacy policies.
